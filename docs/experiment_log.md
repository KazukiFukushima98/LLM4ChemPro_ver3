## run24（2026-07-10 18:01 〜 07-11 06:25、9反復・約12.4h 無人）— ver3 初回・feasible 達成

**条件**：ver3 フル設定の初運転。目的 `minimize_cost`（Lee 2018 経済定数・HX 省略・
CAPEX=C·|WNET|）、Robeson 膜モデル（段別独立 permeance、500–6000 GPU）、Lee 整合 bounds
（面積 [1e5,1.5e6] m²・p_perm [0.1,0.99]・COMP [1,4] bar）、feed 80,307 kmol/h（=500 Nm³/s・
CO₂ 15mol%）、自動中間冷却、目標 purity ≥0.95 / recovery ≥0.90、BO 24/60/4・patience 10。

**結果**：SST が seed（2段直列）から **5膜カスケード＋リサイクルを自律発見し両制約を達成**。
- 最良（iter_008）：purity **0.998** / recovery **0.9014** / **73.66 $/tCO2**（532 kWh/tCO2）
- 構造：2段濃縮 + MEMB3（MEMB1残渣の回収段・透過→V1）+ MEMB5（MEMB3残渣の直列2段目
  回収・これが 0.90 の壁を越えた）+ MEMB4（製品精製段・残渣→V4）+ V6リサイクル。最終 0 バイナリ
  （恒常 ON 段を順次 promote）。
- 軌跡（SHORT→cost）：0.424 → 0.248 → 0.161 → 0.060 → 0.205（iter_005 退行→ロールバック）
  → 0.228 → 0.040 → **0（feasible）** → 0.005。

**停止理由**：固定5段構造のコスト最適点が recovery=0.90 制約の真上にあり、同一構造で BO の
シードノイズが制約線をまたぐ（iter_008: 0.9014 ⇄ iter_009: 0.895）。構造の自由度ではなく
内側最適化器の分散が残課題と診断し、probe せず停止（playbook 準拠）。

**教訓・課題**（詳細は run24/HANDOFF.md）：
1. アクティブ制約近傍の BO 分散（回収 ±0.005〜0.15）が改善信号を不安定化。バイナリ8本
   （256トポロジー）で必須段が落ちて退行（iter_005）→ 恒常 ON 段の promote で空間を絞ると
   回復。→ 高バイナリ時の BO 予算増 or 制約近傍の feasibility 重み付け獲得関数を検討。
2. 純度が過剰達成（0.998 vs 0.95）＝コスト余地あり。
3. コストは真空ポンプ支配（VP 計 ~254 MW、リサイクル3本が全て V1 に戻る 2.2 倍負荷）。
   **未着手の最大レバー＝feed 昇圧アーキテクチャ**（Lee の最適域 2.4–3.5 bar）。リサイクル毎の
   再昇圧 COMP が必要な大規模変更のため、次 run の seed/指示として人間が設計判断する。
4. 運用実測：1反復 20分〜4.1h（バイナリ数とほぼ相関）。SST（LLM）の思考は反復あたり数分で、
   計算時間は Aspen 支配。スキーマミス1回（"changes" キー）は自己修正—— apply_ss に
   空適用ガードを追加済み（`f5c1ff3`）。ロールバック機構・再適用 --force も実戦で機能。

**参照値との関係**：73.66 $/t は Lee の 36.3〜42.5 $/t より高いが、既知の系統差
（膜モジュールが Lee の向流モデルより保守的＝同仕様に多面積、feed 昇圧未使用）と整合。

## run25（2026-07-14〜15）— 昇圧空間での SST・52.12 $/tCO2（run24 比 −29%）

**セットアップ**：昇圧 campaign やり直しの第1走（`f2424a1`）。seed に固定 COMP1
（feed 1 bar → V9 合流点 → COMP1 → MEMB1、pout ∈ [1.1, 4.0] の連続変数）を導入した
2膜直列から開始。他条件は run24 と同一（Lee スケール・目標 0.95/0.90・BO 24/60/4・
patience 10・minimize_cost）。Mixer 規則(4)（素通し給餌のユニット入口を Mixer 化）を
同コミットで追加——導入時の実機 smoke で pre-mixer 配置が全評価 silent BAD になる
builder の穴を発見・修正したもの。

**結果**：**best = iter_004: 52.12 $/tCO2**（purity 0.972 / recovery 0.903 / 542 kWh/t / 260 MW）。
- 構造：COMP1(4.0 bar) + 3膜（MEMB3 は V3 残渣の回収段）+ V6→V9 全量リサイクル。
- 軌跡（7反復・943評価）：未達0.283 → **feasible 107.28** → 未達0.019 → **52.12 ★**
  → 未達0.020 → 68.55 → 52.82。未達3回はいずれも「MEMB3 OFF の2膜構成」盆地に
  BO が吸われて回収88%の壁で patience 切れ＝promote による空間縮小（バイナリ 5→3→2）で解消。
- **run24（真空のみ）73.66 → 52.12（−29%）**。昇圧の解禁が主効果で、feed 昇圧は
  全 feasible best で上限 4 bar に張り付き。

**確定知見**：(1) 3段目回収段は feasibility の必要条件（feasible/未達と MEMB3 ON/OFF が完全対応）。
(2) V6→V9 全量リサイクルは全 best で恒常 ON（組成マッチの V6→V4 は一度も選ばれず）。
(3) EXP（4 bar 残渣の膨張回収）は動作するがコスト最適でない（劣位盆地でのみ採用、
52 盆地では bypass＝CAPEX 500 $/kW が回収益超過）。(4) 役割分担膜（1段目高透過・
2段目高選択）を BO が自力再発見（Lee Fig.5b と同結論）。

**停止理由**：iter_005〜007 の3反復連続で best 未更新（収束）。詳細は run25/HANDOFF.md。

**次**：同じ昇圧空間で baseline（ss_lee2/ss_lee3 の一括最適化、各段固定 COMP 入り）を
回して SST と比較（12.6 本命）。Lee 絶対値（36〜42 $/t）との残差分は
膜流動様式（向流 vs GasPermModule）が支配、他は保守側簡略化（リサイクル膨張回収なし）
と楽観側（HX コスト省略 ~2%）。
